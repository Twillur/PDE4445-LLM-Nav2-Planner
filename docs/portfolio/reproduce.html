01 / No API key required

Run the software checks.

# From the repository root, using an environment with pytest + jsonschema:
python -m pytest ros2_ws/src/nl_nav2_executor/test -q

# Deterministic replay of the saved v3 branch, with A unavailable:
python ros2_ws/src/nl_nav2_executor/scripts/dry_run.py \
  --plan docs/validation/execution-check-20260911T172852Z/v3-L4-12-trial0.json \
  --blocked storage_zone_a

The expected successful visit is storage_zone_b. Without --blocked, only A is visited. Blocking both A and B produces exit code 1. These are mock navigation checks; no robot moves.

# WSL: rebuild and verify installed ROS imports and runtime resources
bash setup/verify-runtime-fixes.sh
02 / In WSL Ubuntu 22.04

Run the actual warehouse.

# ROS2 Humble, Gazebo Classic 11, Nav2 and TurtleBot3 packages must be installed.
source setup/sim-env.sh
cd ros2_ws
colcon build --packages-select nl_nav2_executor --symlink-install
source install/setup.bash
ros2 launch nl_nav2_executor warehouse_sim.launch.py

In a second terminal, from the repository root:

source setup/sim-env.sh
source ros2_ws/install/setup.bash
ros2 run nl_nav2_executor execute_plan \
  --plan docs/validation/execution-check-20260911T172852Z/v2-L1-01-trial0.json \
  --map map/warehouse_map.json

Wait for both the map-server and navigation lifecycle managers to be active. The robot starts at the charging dock. Exit code 0 means completed execution; 1 means incomplete, aborted or deferred; 2 means rejected input. A fallback success is reported separately from reaching the primary destination.

The current executor differs from the one used for the earlier 9/9 replays. See the correction record and its preserved original files. Running old plans on new code is not an exact reproduction of old runtime behaviour.
03 / Optional live model call

Type a new command.

# Configure an API key privately in the environment or local .env.
# The following command makes one billed API call.
export PROMPT_VERSION=v2
python src/run_pipeline.py "Go to the loading dock" \
  --out /tmp/warehouse-plan.json

The bridge validates the returned plan before writing an executable output. A clarification response does not trigger navigation. Select v3 explicitly for the fallback representation; the default planner prompt in the existing source remains v1 unless PROMPT_VERSION is set.

04 / Visual artifacts

Rebuild the presentation material.

# In a Python environment with Matplotlib:
python setup/build-portfolio-figures.py
python setup/build-portfolio-pages.py

# Open docs/portfolio/index.html directly, or serve the repository locally:
python -m http.server 8765 --bind 127.0.0.1
# Then visit http://127.0.0.1:8765/docs/portfolio/

# Genuine new Gazebo captures (WSL; requires Xvfb, ImageMagick, xdotool):
bash setup/capture-portfolio.sh
bash setup/capture-portfolio.sh detail

Capture scripts create dated directories and stop only the process groups they launch. Raw frame sequences and ROS logs stay out of the presentation pack. Rebuilding the report uses report/revised/build.ps1; MiKTeX must be available.
